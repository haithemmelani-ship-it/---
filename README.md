# نادي الأثير للثقافة والعلوم ـ جامعة صالحي أحمد النعامة

منصة طلابية تهدف إلى نشر الثقافة والآداب، تنمية روح البحث العلمي والابتكار، وتنظيم الملتقيات والورشات داخل جامعة صالحي أحمد ـ النعامة.

## أقطاب النشاط
- **القطب العلمي والتقني:** الورشات التطبيقية، تبسيط العلوم، والبحث العلمي.
- **القطب الثقافي والأدبي:** الصالونات الفكرية، نوادي القراءة، والتراث المحلي.
- **الإعلام والمبادرات:** المحتوى الرقمي، التغطية الإعلامية، والعمل التطوعي.
